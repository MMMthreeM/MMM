# 材料需求管理平台 - 專案執行計畫

版本：最終討論版 v2.0
更新日期：2026-10-28（台灣時間）
本文件整合本次已確認需求、實作進度、部署與驗收待辦；功能細節以同目錄「材料需求管理平台 - 設計規格確認書.txt」為準。

一、交付原則

1. 手機優先，並改善桌機叫料及管理批次處理效率。
2. 使用台達電 Delta Electronics 品牌色彩方向：藍色主操作、綠色輔助完成；警示須同時有文字，不只依賴顏色。
3. 訂單以整張單據管理，材料為明細；勾選數以「張」計算。
4. 使用者的「自己」指所屬整個工班，不限本人建立的單據。
5. 權限、狀態、材料、數量及必要版本由後端驗證。
6. 未提供的單位、現行價格與工班對應不猜測；無法對應時提示確認。
7. 程式完成、本機測試、部署成功與正式服務驗收分開記錄，不以本機通過推定正式上線。

二、已完成的程式工作

[x] 1. 基礎架構與權限
    - Next.js、React、Tailwind CSS、Google Sheets、Google OAuth／NextAuth。
    - Users 登入白名單、Admin／User 角色；API 重新檢查身分、角色及工班。
    - 同工班共享正式單與草稿；一般使用者不可跨工班，管理 API 僅限 Admin。
    - 材料 Price 僅供後端匯出讀取，前端材料 API 不回傳。

[x] 2. 角色首頁與導覽
    - 管理員首頁為管理工作總覽：待審需求、審核中、準備出貨、最久等待資訊。
    - 使用者首頁為整個工班的材料儀表板。
    - 漢堡選單依角色顯示建立訂單、歷史需求單、儀表板，以及管理工作總覽／審核中心。
    - 草稿在歷史需求單獨立分頁，不另設頂層選單。

[x] 3. 手機申請流程重構
    - 「選擇材料 → 確認並送出」兩步驟。
    - 可先選廠商縮小範圍；名稱、規格、標籤多關鍵字搜尋，每頁最多 8 筆。
    - 前後端驗證正整數、最低量與級距；支援其他自填材料。
    - 清單可新增、修改、移除；取消修改不遺失原項目。
    - 桌機限寬 1080px，材料與清單並排；數量加減集中於 240px 內。

[x] 4. 歷史需求單
    - 預設「進行中」，退回待修改優先，再待審核、審核中；提供狀態快捷篩選。
    - 草稿獨立；準備出貨、已送達集中「出貨與完成」。
    - 可修改階段提供修改／刪除，鎖定單據可整單重訂。
    - 每頁 10 張，支援單號、日期篩選與返回最上方。

[x] 5. 審核中心、整單狀態與退回
    - 同單號的識別、工班、主要狀態只出現一次；勾選即整單全部材料。
    - 預設最近一個月，由後端限制日期回傳；可清除日期查舊單。
    - 材料／廠商篩選保留符合單據的全部明細，更換篩選清除勾選。
    - 後端驗證整單狀態／工班一致性、合法轉換及必要材料版本。
    - 整單退回可選共用原因或指定材料原因；整張狀態一起退回。
    - 有有效退回原因的處理中單據統一顯示「退回待修改」；重新送出後恢復待審核。
    - 待審數不混入退回待修改。
    - 管理員用編輯圖示修改處理中、審核中材料／數量／備註，可新增移除材料。
    - 管理編輯保留原申請人、工班、日期與進度；筆數變更以單次 Sheets 批次寫入完成。

[x] 6. 材料儀表板
    - 使用者看整個工班，管理者看全工班及指定工班匯總。
    - 材料、日期、狀態篩選；管理端另有工班條件。
    - 呈現需求單數、材料種類、常用材料、月份需求及材料／工班明細。
    - 草稿不列入；同單同名同單位頻率計一次，數量逐筆加總，不同單位分開。
    - 材料／工班明細每頁 20 筆；完整統計不受分頁影響。

[x] 7. 匯出與重匯
    - 篩選範圍匯出：全部符合條件的審核中完整單據，與勾選無關；成功後轉準備出貨。
    - 勾選匯出：審核中會轉準備出貨；準備出貨、已送達可重匯，維持原狀態。
    - 伸泰、益詮各一份 .xlsx，提供 ZIP 與個別下載。
    - 沿用原始範本的固定工班欄、材料列與樣式，取消原版動態雙分頁設計。
    - 未叫料留空；同廠商同名同單位重複列匯總最上方列，其餘空白。
    - 系統「鶴峻」對應來源鶴峻／鶴竣欄；其他未知對應須確認。
    - 先完成報表，再重查狀態與材料版本，才推進需出貨的單據。
    - 產檔或檢查失敗不推進；找不到材料、廠商、工班對應不漏列、不猜測。

[x] 8. Telegram、公告、回報與監控
    - 正式送單、退回、進度更新、問題回報已有推播程式。
    - 預計交期選填；有值附「交期依廠商回覆為主」，空白不顯示交期欄。
    - Vercel Cron 設每天台灣時間 09:00、含假日，既有管理群組主題 30。
    - 目前每天發摘要，待審數含 0，退回待補件數另列，並提供最久等待資訊。
    - CRON_SECRET 驗證排程；TG_TOPIC_PENDING_REVIEW=30 指定主題。
    - 已有 System_Notices 公告、Sentry 設定及回報問題介面；不將新增公告自動 TG 推播列為完成。

[x] 9. 材料庫與資料檢查
    - 五分頁欄名及排列符合目前程式。
    - 產出可貼上的 135 筆材料：伸泰 32、益詮 103，附來源與檢查結果。
    - M001 原設定保留：最低量／級距 100／100、Price 10，以及原 ID／名稱／標籤／廠商／單位。
    - 新材料最低量／級距先 1／1；包裝文字不推定訂購規則，未提供標籤保持空白。
    - 益詮缺單位 10 列另列待確認，其中混合材料列需拆分確認。

    - 修改、重訂與後端驗證依名稱＋廠商＋單位辨識，避免跨廠商同名誤配。
    - 未直接修改正式 Google Sheets 或原始資料庫 Excel。

2. 依使用者指定，不重構 Sheets 全表讀取／刪列／寫入架構；多人同時操作與跨執行個體仍可能競爭。
3. 重新檢查及單次批次寫入不是跨請求交易或鎖定保證。

5. 排程未具跨執行個體去重保證，不另外建立 Codex 聊天排程。
6. 原規格 PWA／離線操作未列入本次完成驗收；有 manifest 不等於離線可用。
