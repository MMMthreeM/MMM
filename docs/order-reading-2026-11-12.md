# 需求閱讀與總覽風格統一（2026-11-12）

依使用者確認，先以需求詳情建立全站閱讀規則，再套用歷史清單、管理審核、分析相關需求及雙角色首頁。需求詳情按狀態與下一步、基本資料、材料清單、處理紀錄排列；保留既有白底、藍色操作及狀態色。

## 實作

- 共用 `OrderSummary`、`OrderFacts`、`OrderMaterials`，減少各頁重複排版。資料讀取、權限、價格隱藏及後端寫入契約沿用。
- 清單以日期與狀態為主要辨識，工班／申請人／筆數次之，單號作為次要參照。摘要材料限制兩行，展開後保留整單完整材料。
- 材料名稱、數量／單位、備註分層；管理廠商及核對資訊獨立呈現。管理詳情保留地區、審核人與交期。
- 手機詳情主要修改入口置於狀態區，再訂／刪除入口置於下方，取消會覆蓋內容的 sticky 詳情操作列。刪除結果不確定時仍禁止重送。
- 雙角色首頁共用待辦工作面與需求摘要；管理端待辦順序反映集中審核、採購安排、送達追蹤及等待工班修改。
- 兩種角色的分析頁共用標題與明細樣式；管理員保留地區及工班篩選，材料／月份下探規則沿用。
