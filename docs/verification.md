# 操作規則與驗證

- 登入後：管理者進入管理工作總覽；使用者進入整個工班的材料儀表板。
- 管理審核以整張單據為單位。單號、請購工班與狀態只顯示一次；勾選數以單數計算。材料或廠商篩選會保留符合單據的全部材料。更換篩選時清除選取。
- 匯出依目前篩選範圍，只取狀態一致且為「審核中」的完整單據，與勾選無關。確認後由後端重讀資料、產生 Excel，再重新檢查狀態並轉為「準備出貨」。若報表產生或狀態檢查失敗，不會推進狀態。檔案成功回傳後可在同頁重新下載。
- 草稿由同工班共用，放在歷史需求單的獨立分頁；不出現在管理審核清單或需求統計。
- 叫料頻率為包含該材料的正式需求單數；同張單的同名同單位材料頻率只計一次，數量逐筆加總。統計以最近送出／更新日期篩選，各單位的需求量分開計算。
- 待審天數自最近送出／更新時間起算，採台灣時間。既有資料沒有獨立的首次收件時間，因此不宣稱為首次收件後的天數。

## 驗證方式

`npm test` 使用模擬的登入資訊與 Google Sheets，涵蓋角色權限、跨工班隔離、整單狀態更新、不合法轉換、匯出檔案內容、失敗不推進狀態與草稿送出驗證。測試不會連線或修改正式試算表。

`npm run test:ui` 需先啟動本機網站，並具備 Playwright。可用 `PLAYWRIGHT_MODULE_DIR` 指定既有套件目錄，`UI_BASE_URL` 指定網址（預設 `http://127.0.0.1:3000`），`UI_ARTIFACT_DIR` 指定截圖目錄。Windows 預設使用背景 Edge；其他系統使用 Playwright Chromium，可用 `UI_BROWSER_CHANNEL` 覆寫。所有資料 API 都由測試攔截並回傳模擬資料，不會寫入正式資料。檢查桌機、390px 手機排版、角色導覽、整單勾選、匯出失敗回饋與成功轉出貨。

## 範圍與限制

保留既有四位隨機訂單號，以及 Google Sheets 全表讀寫／刪列架構；跨執行個體的同時寫入仍不具交易保證。測試不等同正式 Google OAuth、Telegram 與真實試算表的端到端驗證。

開發環境曾在更新 CSS 後持續使用舊的自訂 loader 磁碟快取，重啟仍未更新；目前停用 Turbopack 開發與建置磁碟快取，以確保產物與來源一致。

## 第二輪可用性調整

- 建立需求頁限寬 1080px，桌機並排顯示材料選擇與待送出清單；數量操作固定在 240px 內。修改材料時，原項目保留到按下儲存，取消修改不會遺失資料。
- 材料搜尋支援多關鍵字，每次最多呈現 8 筆，可繼續縮小搜尋或切換結果頁。申請、審核與儀表板共用搜尋元件。
- 歷史單與審核清單每頁 10 張，材料及工班統計每頁 20 筆；篩選改變時回到第一頁。完整統計不受目前分頁影響。頁面底部提供返回最上方。
- 審核清單預設最近一個月，並在後端限制回傳的日期範圍；清除日期可查較早單據。管理首頁與統計保留全期統計。這會減少回傳與畫面渲染量，尚未改變試算表本身的全表讀取架構。
- 整單退回原因改放單據上方一次呈現；也可指定材料列顯示原因，整張單仍一起退回。用後端產生的材料列識別區分同名材料，失效識別會拒絕更新。
- 填寫預計交期時，Telegram 訊息加註「交期依廠商回覆為主」；未填日期則不顯示交期欄位。
- 勾選匯出支援審核中、準備出貨與已送達；只有審核中會轉準備出貨。其他階段重新匯出維持狀態，不重複發出交期通知。兩份報表全數完成與壓縮成功後，才嘗試推進新出貨的需求單。
- 管理員可由單據上的編輯圖示修改處理中、審核中的材料、數量與備註，可新增或移除材料；保留原申請人、工班、日期與進度，並記錄實際修改者。準備出貨、已送達不可編輯。儲存時確認材料版本；筆數改變時以同一個 Sheets 原子批次完成刪除、插入與寫值，失敗不留下半張單。
- 每日提醒為台灣時間 09:00、含假日，Vercel 排程發送至管理群組主題 30。部署前需在 Vercel 設定 `CRON_SECRET`；詳見 `daily-reminder.md`。
- 匯出依伸泰、益詮各產生一份 `.xlsx`，保留範本全部有資料及說明的列，未叫料顯示空白。下載全部時使用 ZIP，亦可個別下載。字型、字級、字色、底色、對齊、框線、數字格式、欄寬、列高與隱藏欄位依原 `.xls` 擷取並驗證；匯出填值時不重寫樣式 XML。原檔中的大量尾端空白列不帶入。
- 材料對應依廠商、名稱、單位；同名同單位的重複列匯總至最上方一列，其餘保留空白。工班名稱統一以「鶴峻」對應兩份範本的原始欄位。找不到對應時阻擋匯出，不漏列也不改變狀態。單價使用後端材料庫的目前資料；缺少單價時留空，不套用舊範本價格。舊 PR/PO 與出貨紀錄會清空。

## 材料分類與快速下訂

- Materials 支援分類、細分類、搜尋別名、叫料提示與必填備註等欄位；保留舊欄位相容性。完整欄位與資料貼上方式見 `material-catalog.md`。
- 叫料頁提供全部、常用、最近選用三個入口，並可依分類及廠商縮小範圍。搜尋支援相連的中文與規格、全半形及常見單位寫法，例如「1.25黑線」。選好材料後才展開數量與備註。
- 常用與最近材料存在目前瀏覽器，按帳號與工班區分；依材料名稱、廠商、單位識別，材料短編號更換後仍能保留。這些偏好不會寫入工班共用資料。
- 混合材料保留完整原名與簡短顯示名稱，前後端都驗證品項備註必填；價格不會出現在公開材料 API。
- 本輪以 208 筆實際材料加上 241 筆模擬材料驗證搜尋、分類、常用保存、最近選用、混合材料備註及手機長文字。所有 API 仍由測試攔截，不會連線正式 Google Sheets。
