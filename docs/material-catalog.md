# 材料分類、搜尋與匯入

Materials 保留原有 A:H，另新增 I:N。請完整貼上 A:N；既有舊表仍能讀取，未填分類的材料會列為「其他材料」。Price 僅供後端使用，材料 API 不會回傳。

| 欄位 | 用途 |
| --- | --- |
| Item_ID | M1、M2 等短編號。請保持唯一，新增料件使用下一個未使用編號；不要重用已移除編號。 |
| Tags | 以逗號分隔，包含材料用途、字面規格、顏色等搜尋標籤。 |
| Category | 大類，例如電線電纜、燈泡燈管、安裝五金。 |
| Subcategory | 細類，例如管夾、燈座轉接頭；選定大類後可再縮小範圍。 |
| Search_Aliases | 常用叫法，例如黑線、歐姆夾、螺母。以逗號分隔。 |
| Order_Hint | 選料時顯示的叫料說明，例如「1 箱代表整箱」。 |
| Requires_Remarks | TRUE 時，前後端都要求品項備註，草稿與正式單均驗證。 |
| Display_Name | 可選的簡短顯示名稱；Item_Name 仍保留完整規格，訂單使用完整名稱。 |

材料以「名稱＋供應商＋單位」識別。名稱相同但以個、箱下訂時，保持不同編號，不自行換算箱內數量或單價。混合材料依使用者要求保留一項，以「項」計數，完整內容保留於 Item_Name，需在備註確認各項數量。

搜尋會處理全半形、mm²／mm2、吋／英吋、相連的中文與規格，例如「1.25黑線」。多個條件均須符合，名稱完全相符者優先。結果每頁最多 8 筆。

常用材料最多 40 種，最近選用最多 8 種，按登入帳號與工班分開存在目前瀏覽器；不是全工班共用紀錄。依名稱、供應商、單位保存偏好，因此更換短編號仍可保留收藏。清除瀏覽器資料會移除偏好；無法持久儲存時，本次開頁仍可使用。

更新流程：先備份 Google Sheets，部署相容的新程式，再貼上新版 Materials A:N。歷史資料檔的 Orders 僅含本次整理的 102 張歷史單，請按檔內說明追加一次；如果已匯入早期版本，先按 HIST 編號及材料來源比對，不能整份再追加。舊新材料編號對照另附在 Excel，既有訂單不會因材料編號更換而重寫。

新增分類與標籤不改動原廠商報表對應規則。新供應商或無對應的混合材料，仍須由管理者確認報表格式與規格對應，不能直接套用另一家廠商範本。

驗證：`npm test` 涵蓋欄位相容、價格不外洩、備註必填與搜尋排序。`test:ui` 可用 `UI_CATALOG_PATH` 指定不含價格的材料 JSON，額外驗證真實材料分類、常用保存、最近選用、鍵盤選料與手機長文字。
