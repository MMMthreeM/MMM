# 功能命名對照（2026-10-29）

| 名稱 | 對應功能 | 範圍 |
| --- | --- | --- |
| 維運材料管理平台 | 產品名稱；英文 Maintenance Materials Management | 全站 |
| 管理工作總覽 | 待審、審核中與準備出貨工作佇列 | 管理員首頁 / |
| 材料審核中心 | 整單選取、狀態變更、退回、管理員編輯、報表匯出 | /admin |
| 需求分析儀表板 | 導覽入口；頁面標題依角色為各工班／所屬工班材料需求儀表板 | Admin /analytics；User / |
| 建立材料需求 | 選擇材料、確認並送出或儲存草稿 | /request |
| 歷史需求單 | 所屬工班正式需求與共享草稿；不等於管理員全工班歷史 | /dashboard |
| 材料總覽 | 目前篩選內的材料叫料頻率、數量與單位 | 儀表板 |
| 材料趨勢 | 每月正式單數，或選定材料的需求量；不同單位分圖 | 儀表板 |
| 工班明細 | 全工班／指定工班的單數、材料種類與最近需求 | 管理員儀表板 |
| 期間訂單明細 | 整個篩選日期範圍的相關完整需求單 | 儀表板 |
| N 年 N 月的需求單 | 趨勢圖選定月份、沿用材料／工班／狀態篩選 | 儀表板 |
| 開始審核 | 待審核轉為審核中；不是完成審核或出貨 | 管理員 |
| 匯出並轉準備出貨 | 篩選內審核中整單產檔成功並通過重查後推進 | 管理員 |
| 匯出勾選單據 | 僅匯出所勾完整單據；審核中推進，準備出貨／已送達重匯不改階段 | 管理員 |
| 整單重訂 | 以舊單材料建立新需求，不修改原單 | 工班歷史 |
| 預計交期 | Expected_Date 選填，依廠商回覆為主；不代表保證送達日期 | 全站 |

原始狀態：編輯中→畫面「草稿」；處理中無有效退回原因→「待審核」；處理中有有效原因→「退回待修改」。其餘維持「審核中／準備出貨／已送達」。不新增已出貨、已完成或獨立退回狀態欄值。
管理員選單將管理作業與工班作業分區；需求分析是分析用途，歷史需求單是所屬工班的修改、送出、重訂用途。
