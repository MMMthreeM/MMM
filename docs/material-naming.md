# 材料命名與報表對應

只為了讓工班看得懂，建議修改 Materials 的 Display_Name，不改 ID、Name、Vendor、Unit。Display_Name 會顯示於選料與文字叫料候選，Search_Aliases 可加入常用叫法；正式 Name 繼續作為訂單識別。

## 已修改 Name 的材料

在 Materials 新增以下欄位。部署依表頭讀寫新版後，可自由調整欄位順序：

| 欄位 | 用途 |
| --- | --- |
| Report_Name | 填入廠商範本的完整原始材料名稱。留空時沿用 Name。 |
| Export_Aliases | 歷史訂單曾使用的舊料名；多個名稱以分號或儲存格內換行分隔。僅供後端匯出對應，不作為前端搜尋別名。 |

範例：Name 可是「綠色電線」，Report_Name 填「1.25mm2-1C絞線(綠色)」，Export_Aliases 填曾經使用的舊名稱。Vendor 仍是伸泰、Unit 仍是 M。

對應同時核對材料名稱、單位及廠商，不會猜測規格或跨單位換算。別名若指向不同報表材料、同一材料有不同單價，匯出會阻擋。修改料名不會自動更新歷史 Orders；舊料名須保留為 Export_Aliases，才能以明確對應匯出。不要變更材料 ID。

你提出的「1.6mm2 -1C 單心/黑色 (100M/丸)」，伸泰範本的近似名稱為「1.6mm單芯(黑色)- (100M/丸)」。mm 與 mm2 分別可能代表直徑與截面積，必須先確認確實為同一規格，再填 Report_Name；程式不會自動建立這一組對應。

完整範本名稱可查閱 [匯出材料對照表](export-material-reference.md)。模板的名稱、字型、底色與表格格式仍保留。自填材料若未建立明確廠商及範本對應，可送單，但管理員匯出前仍須指定正確材料。

## 稽核時間

新稽核事件及尚未補寫的 ISO 時間改用台灣時間 yyyy-MM-dd HH:mm。已寫入 Google Sheet 的舊紀錄不自動改動。
