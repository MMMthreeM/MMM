# 材料採購對應與獨立匯出（2026-11-01）

## 管理員操作

1. 在材料審核中心勾選完整需求單，按「開始審核」。更新成功後，畫面切至審核中；其他地區、工班與日期條件保留。
2. 點單據的「材料／廠商對應」或編輯圖示。每筆可以選既有材料，或以其他（自填）保留名稱、單位，再指定本次供應商：伸泰、益詮、賀冠。暫時換供應商不必複製 Materials。
3. 確認全單材料、數量、單位、備註與供應商後，按「完成審核」轉為審核完畢。這是整單採購確認，不等於出貨。
4. 安排交貨時按「設為準備出貨」，可填預計交期，也可以留空。只有填寫時，TG 進度通知才顯示交期並附依廠商回覆為主。
5. 送達後按「標記已送達」。審核完畢或準備出貨如須修改，可先整單退回；已送達不可退回。

各次狀態操作成功後，清除勾選、回第一頁並切至目標狀態；退回切至退回待修改。狀態與工班不一致的需求不可批次處理。

## 匯出 Excel

「匯出篩選範圍」取目前符合篩選的全部正式完整需求，與勾選無關。「匯出勾選單據」只取勾選完整需求。最多 200 張。待審核、退回待修改、審核中、審核完畢、準備出貨、已送達均可匯出；草稿排除。所有材料仍須通過資料與供應商檢查。

匯出只產檔，不寫 Orders、不推進狀態、不發出貨通知。可隨時重新下載或重匯，不必為誤按匯出退回訂單。重匯使用目前資料與價格，不是原匯出快照。

- 只要選單含伸泰或益詮，產生兩份原範本 .xlsx，支援 ZIP 與各檔下載。
- 保留所有原範本材料列、固定工班欄、樣式與說明。同名同單位重複列填最上方，未叫料數量留白。
- 已確認材料不在指定供應商範本時，在最後材料下一列新增；後續列、公式參照、列印範圍同步調整，沿用前一材料列樣式與高度。
- 相同供應商、報表名稱、單位彙總到同一列，各工班填各自欄位。工班無範本欄位時阻擋並要求確認，不自行發明工班欄。
- 單價只取目標供應商對應材料；跨廠商無有效價格留空，不沿用原供應商價格或範本舊價格。
- 優先使用目標供應商的 Report_Name／Export_Aliases；有 Material_ID 且目標沒有名稱對應時，使用原材料的報表名稱。不同單位不自動換算。
- 產檔後重查需求版本，已變更則要求重新確認，避免下載過期選單。

## 賀冠詢價

勾選含賀冠材料的需求，按「賀冠詢價」。視窗包含工班、單號、賀冠品項、數量／單位及材料備註，可修改文字後複製到通訊 App。程式不會自動送訊息、不輸出賀冠 Excel、不更改狀態。混合廠商匯出後另開賀冠文字視窗；全部只有賀冠時，請直接按賀冠詢價。

目前以整單驗證為邊界：同單其他材料仍未指定供應商或不符規則時，需先完成對應，才產生詢價／報表，不會默默略過有問題的材料。

## 資料欄位與安全

Orders 新增兩個選填表頭，缺少時由管理員編輯在同一次批次中補上，欄位位置不限：

| 表頭 | 用途 |
| --- | --- |
| Material_ID | 已對應的 Materials.Item_ID。供應商臨時改派仍保留材料庫規格來源；純自填留空。 |
| Original_Item_Name | 管理員編輯前的原需求名稱，供對照；既有列再次編輯保留原值，新增材料使用本次名稱。 |

舊單缺少以上欄位仍可讀取；以名稱、單位與原供應商辨識。新送單在表頭存在時寫入所選材料 ID 及名稱。再次載入歷史單／退回單時，有材料 ID 則回到該材料庫規格與預設供應商，管理員可以重新指定本次供應商。不要重用已有訂單引用的材料 ID。

材料／廠商對應限管理員，且只能編輯處理中、審核中；檢查原狀態及材料版本。前端材料 API 不提供單價。既有來源驗證、限流、共用協調鎖與稽核保留。匯出與詢價屬不寫 Orders 的操作，產檔失敗不留下未知訂單寫入鎖，但仍需要既有 Upstash 設定。沒有新增環境變數。

部署新版不會自動回溯更改既有準備出貨或已送達單據。請以獨立測試資料驗收跨廠商、範本外材料、賀冠及 TG 通知，再安排正式使用。
